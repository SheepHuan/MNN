# PIC Optimization Logs

优化日志按 `log/<device>/<hour>/` 存储，`hour` 目录名格式为 `YYYY-MM-DD-HH`。每个小时目录固定包含：

- `README.md`: 当小时摘要和入口。
- `context.md`: 长上下文、实验细节和原始结论。

历史从 day 级目录迁移到 hour 级目录时，如果原日志没有可靠小时信息，统一落到 `HH=00`。
