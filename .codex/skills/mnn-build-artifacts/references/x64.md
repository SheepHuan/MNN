# x64

适用场景：

- 本地 Linux x64 构建和检查 MNN 产物

## 默认入口

```bash
cmake -S . -B .cache/build/mnn/x64 \
  -DMNN_CUDA=ON \
  -DMNN_SUPPORT_TRANSFORMER_FUSE=ON \
  -DMNN_BUILD_LLM=ON \
  -DMNN_BUILD_CONVERTER=ON \
  -DMNN_BUILD_SHARED_LIBS=ON

TOTAL_CPUS="$(nproc 2>/dev/null || getconf _NPROCESSORS_ONLN)"
JOBS="${JOBS:-$((TOTAL_CPUS > 1 ? TOTAL_CPUS / 2 : 1))}"

cmake --build .cache/build/mnn/x64 --parallel "${JOBS}"
cmake --install .cache/build/mnn/x64 --prefix .cache/output/mnn/artifacts/x64
```

只重编某个 target：

```bash
cmake --build .cache/build/mnn/x64 --target <target> --parallel "${JOBS}"
```

## 产物检查

```bash
file .cache/output/mnn/artifacts/x64/bin/MNNConvert \
     .cache/output/mnn/artifacts/x64/lib/libMNN.so
```

## 常见失败点

- 忘记开 `MNN_BUILD_LLM`
- 忘记安装到 `.cache/output/mnn/artifacts/x64`
- 混用别的 build 目录导致旧 target 残留
